Smart Expense Tracker
A simple and user-friendly web application to manage personal income and expenses.

Project Objective:
The Smart Expense Tracker helps users record, manage, and analyze their daily financial transactions in one place.

Features:
* 🔐 User Registration and Login
* 🚪 Secure Logout
* ➕ Add Income and Expense Transactions
* ✏️ Edit Transactions
* 🗑️ Delete Transactions
* 🔍 Search Transactions
* 📅 Filter Transactions by Date
* 📊 Spending Analysis using Pie Chart
* 💰 Monthly Income, Expense and Balance Summary
* ☁️ Firebase Cloud Firestore Database
* 🌐 Deployed using GitHub Pages

Technologies Used:
* HTML
* CSS
* JavaScript
* Firebase Authentication
* Firebase Cloud Firestore
* Chart.js
* GitHub Pages
* Visual Studio Code

Firebase:
Firebase Authentication is used for user login and registration.
Cloud Firestore is used to securely store and manage transaction data.

How to Use:
1. Open the Smart Expense Tracker website.
2. Create a new account using the Register page.
3. Login using your email and password.
4. Add income or expense transactions.
5. View monthly financial summaries.
6. Analyze spending using the pie chart.
7. Edit or delete transactions whenever required.
8. Logout after completing your session.
